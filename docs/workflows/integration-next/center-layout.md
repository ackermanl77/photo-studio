# Centered Editor Layout

## Launch

```powershell
streamlit run app/frontend_center.py
```

After upload, the page uses this order:

1. Original image and edited preview centered across the top.
2. A full-width editing workspace below the images.
3. All post-upload controls in tabs: Look, Tone, Color, Detail, Curves, Layers, Repair, Catalog, and Export.

No editing tools are placed in the right sidebar after the image is loaded. The sidebar is not used by this entry point for post-upload controls.
