# Library-to-Editor Workflow

## Launch

```powershell
cd "C:\Users\MELEJ\OneDrive\photo_professional_tool"
C:\Users\MELEJ\AppData\Local\Python\pythoncore-3.14-64\python.exe -m streamlit run app/frontend_library_editor.py
```

## Steps

1. Choose a local photo folder.
2. Scan the folder and include subfolders when needed.
3. Search by filename, path, or catalog tag.
4. Filter by minimum rating.
5. Select an indexed image.
6. Apply a preset and core tone/color corrections.
7. Compare the original and edited image.
8. Download a JPEG delivery copy.

The selected image is opened directly from the catalog path, so it does not need to be uploaded again.
