## Steps

1. Open an existing `.photoproject`, or start with a source image.
2. Review the restored source and layer list.
3. Add an optional overlay layer.
4. Compare source and composite previews.
5. Save the updated `.photoproject`.
6. Download a flattened composite when needed.

Project archives preserve the source, recipe, layers, and masks together.
